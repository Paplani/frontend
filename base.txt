타입스크립트 : 자바스크립트에 타입을 지정
node 이름.ts 로 터미널 실행이 불가능함
ts는 무조건 js 로 변환된 후 실행되어야 한다.

node npm : Node Package Manager의 약자 => Node.js 패키지(라이브러리) 관리자
    다른 사람이 만들어 놓은 라이브러리 설치하고 관리 가능

npm install -D 패키지명 : 개발용 패키지 설치 (개발할 때만 필요한 프로그램)  ex: typescript, prettier, vite...
-D (== --save-dev)
-g (-- --global)

<1번>
npx : 설치된 패키지의 실행 파일을 실행하는 도구
tsc를 이용해서 타입스크립트 파일을 js로 컴파일 : npx tsc src/test => test.js => node test



<2번>
tsc --init : tsconfing.json (타입스크립트 환경설정 정보 저장)을 생성
ts 파일 작성 => 컴파일 => js 파일 실행

<3번>
npm i -g ts-node 를 설치
ts-node : 타입스크립트를 컴파일 없이 바로 실행
npx ts-node src/test
