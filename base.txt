리엑트에서 'use'가 붙어있는 것들을 "훅"이라고 한다. ex:useState
훅: React가 제공하는 특별 함수
    - React의 기능을 사용할 수 있음
    - 컴포넌트의 최상위에서만 호출 가능
    - React의 상태, 생명주기 등의 기능과 연결

useParams / useLocation

useLocation  
- 현재 페이지의 전체 URL 정보를 가져올 수 있는 훅

    => "부모가 렌더링 시 관련없어도 자식 렌더링이 같이 되"는 걸 막아줌 => 부모랑 자식이 관련없으면 렌더링 안되도록 함
    => useMeno() 판단 후 적절하다고 판단ㅇ 되면 이 부분도 해결해줌
    => useCallback() 또한 해결해줌

    useMemo() : 계산결과 기억
    useCallback() : 함수 기억(부모가 자식에게 함수를 props로 넘길때)
    리렌더링 시 함수는 새롭게 생성됨!

useReducer : 관리해야 할 상태 로직이 복잡할 때 사용

useReducer() : 상태를 어떻게 변경할지 관리
useContext() : 상태를 여러 컴포넌트에 어떻게 공유할지 관리

!redux!
1. context로 사용할 객체 생성
2. 생성된 context 객체를 통해 provider 생성
3. 상태를 공유할 자식 컴포넌트를 provider로 감싸기
4. 자식 컴포넌트에서 공유된 값 사용
